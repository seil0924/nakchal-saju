# 대표 사주 해석 규칙 v1

2026-11-03. AI 호출 없이 `saju-interpretation.ts`의 순수 함수로 계산하고 `interpretation-copy.ts`에서 문장으로 조립한다. 원국 계산·음력 변환·절기·시간 보정은 기존 `manse-core`를 사용한다. 적용 범위는 대표 사주와 통합 리포트의 대표 사주 장이다. 다른 상품의 궁합·택일 판정은 변경하지 않는다.

## 근거와 선택한 관례

지장간은 국제평생교육원 공개 「명리심리상담사 강의교안」 PDF 84~85쪽의 여기·중기·정기 표를 따른다. https://www.ili.or.kr/upfiledata/Board/명리심리상담사_이영선_교안모음[1].pdf

자 임계 / 축 계신기 / 인 무병갑 / 묘 갑을 / 진 을계무 / 사 무경병 / 오 병기정 / 미 정을기 / 신 무임경 / 유 경신 / 술 신정무 / 해 무갑임. 마지막 글자가 본기다. 유파별로 다른 표가 있으므로 사용자에게 적용 범위를 표시한다. 이 출처는 전통 규칙의 확인용이며 예측력의 근거가 아니다. 서비스의 성향 문구와 조건별 제안은 자체 편집 규칙이다.

## 합산하지 않는 세 층

- 표면 분포: 기존 천간·지지 대표 오행을 각 1회 센다. 성향 주제의 비중은 일간을 제외한 5/7자리를 센다. 동률은 모두 유지한다.
- 월지: 절기로 계산한 월지의 계절과 본기의 십성을 설명한다. 진·미·술·축은 각 계절의 끝으로 표시하며 본기 토를 그대로 사용한다.
- 지장간: 기운의 존재, 일간과 같은 오행을 품은 지지, 본기·개별 천간의 십성을 별도로 확인한다. 지지 순번의 음양 대신 각 지장간 천간의 음양으로 기존 `starOf`를 호출한다.

받침은 월지 본기가 비겁/인성인지, 같은 오행의 뿌리가 있는지, 일간 외 천간에 비겁/인성이 있는지 세 근거의 일치 여부를 서술한다. 모두 있음/일부/없음으로 나누며 강도 점수·신강신약·용신으로 부르지 않는다. 지장간 개수를 표면에 더하거나 임의 가중치를 붙이지 않는다. 시주 미상은 시주 전체를 제외하고 조건부 해석임을 알린다.

## 상충하는 문장 정리

식상/인성, 비겁/관성, 식상/관성이 표면에 함께 있을 때만 각 역할과 적용 상황을 구분한 설명을 만든다. 재성은 받침 근거와 함께 읽는다. 해당 조합이 없으면 일반적인 조건 안내로 대체한다. 지장간에만 있는 관계를 표면의 우세한 성향으로 승격하지 않는다.

기본 성향, 선택 연도, 오늘을 별도 카드로 표시한다. 기간별 풀이는 기존 일간과 해당 기간 천간의 오행 관계를 재사용한다. 기간이 다르다는 이유로 원국 성향을 바꾸지 않으며, 좋은 흐름을 성공 보장이나 확장 지시로 바꾸지 않는다. 전체 합충·조후·격국·용신 판정은 이번 범위에 포함하지 않는다.

## 전송·회귀 검증

무료는 기본 성향·근거·종합 해석, 유료는 지장간 상세·조건별 풀이·협업·성과·일상 적용이다. 기존 장 키와 서버 레벨 게이팅을 유지한다. 구매 전 유료 HTML을 비워 전송한다. 생시 미상, 동률, 같은 분포/다른 월지, 자오사해 음양, 지장간에만 있는 오행, 기간 분리, 입력 불변성, 다른 상품 격리를 테스트한다.
