## 운영 규칙(재발 방지)
- **웹 에디터에서 기존 파일을 고치는 검증된 절차 (2026-08-25).** Ctrl+A는 CodeMirror 선택을 못 잡는다(선택 길이 0).
  그 상태로 전체 교체를 시도하면 내용이 **덧붙여져** 파일이 깨진다(107줄 → 163줄 사고).
  ① 대상 줄이 보이도록 **마우스 휠**로 스크롤(programmatic scrollTop 은 가상화를 안 깨운다)
  ② 에디터 안을 **실제 마우스로 클릭**(element.focus() 만으로는 부족하다)
  ③ `.cm-line` 을 Range 로 잡고 ④ `document.execCommand("insertText", ...)`.
  **선택 길이를 원문 길이와 대조한 뒤에만 삽입할 것.** setStartBefore/setEndAfter 는 줄바꿈까지 먹으니 치환문 끝에 \n 을 붙인다.
- **한글을 타이핑하면 IME가 한글 모드로 남아 이후 ASCII 입력이 통째로 사라진다.**
  커밋 메시지·파일명은 타이핑하지 말고 input 의 native value setter + `input` 이벤트로 넣는다.
  스크립트·워크플로 주석은 영어로 쓰는 편이 안전하다.
- **명암비 감사기는 반투명 배경을 합성해야 한다 (2026-08-25).** 첫 조상의 배경색을 불투명으로 치면
  어두운 섹션 위 반투명 오버레이가 흰 배경으로 계산돼 멀쩡한 텍스트가 위반으로 뜬다(홈에서 15건 오탐).
  조상 배경을 전부 모아 아래에서 위로 alpha 합성할 것. 정상 결과는 홈 1건(장식 낙관 士, aria-hidden)뿐이다.
- **사이트맵 전수 점검을 라이브에서도 돌린다.** 미들웨어 공개경로 누락은 빌드가 안 잡는다

  `fetch(url,{redirect:"follow"})` 로 최종 경로가 요청 경로와 같은지 대조하면 된다.
- **YAML 을 웹 에디터에서 새로 쓸 때는 flow 스타일로 한 줄씩.** 개행마다 auto-indent 가 누적돼 들여쓰기가 망가진다.
